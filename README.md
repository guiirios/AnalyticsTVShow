# 📺 AnalyticsTVShow

Projeto de análise de dados focado em séries de TV, utilizando Python e Jupyter Notebook para explorar, tratar e visualizar informações relevantes sobre o dataset.

---

## 🚀 Objetivo

O objetivo deste projeto é aplicar técnicas de análise de dados para:

- 📊 Explorar informações sobre séries de TV
- 🧹 Limpar e tratar dados
- 📈 Gerar visualizações
- 🧠 Extrair insights relevantes

Este projeto faz parte do meu desenvolvimento em Data Analytics.

---

## 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 📂 Estrutura do Projeto
AnalyticsTVShow/
│
├── data/ # Dataset utilizado na análise
├── analytics.ipynb # Notebook com toda a análise
└── README.md # Documentação do projeto


---

## 📊 Etapas da Análise

O projeto segue as seguintes etapas:

1. Importação das bibliotecas
2. Carregamento do dataset
3. Análise exploratória dos dados (EDA)
4. Limpeza e tratamento
5. Criação de gráficos
6. Extração de insights

---

## 📈 Exemplos de Análises Realizadas

- Quantidade de séries por gênero
- Distribuição de avaliações
- Séries mais bem avaliadas
- Tendência de lançamentos ao longo dos anos

---

## 🧠 Principais Aprendizados

- Manipulação de dados com Pandas
- Agrupamentos e filtros avançados
- Criação de visualizações
- Organização de um projeto de análise
